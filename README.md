# Banco-de-Dados-de-A-es---Simulador-de-Carteira
Simulador de carteira de ações em C++. Lê histórico de cotações, dividendos e operações via stdin. Suporta consultas de valor, cálculo de dividendos, ordenação e rebalanceamento por aporte. Implementado sem STL — arrays dinâmicos. Implementado com busca binária e ordenação do zero.
